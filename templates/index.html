3 · Test centre

How do I find my location's ID?
  1. Go to ICBC's real road test booking site and start booking a test (you can back out before actually booking).
  2. Open your browser's DevTools (F12) → Network tab, filter to Fetch/XHR.
  3. Select your test centre in the booking flow.
  4. Find the request to getAvailableAppointments, open it, and look at the request payload for "aPosID": <number>.
